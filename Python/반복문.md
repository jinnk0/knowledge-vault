[[Python/Python.md|Python]]의 반복문. `for` 문과 `while` 문 두 가지가 있다.

## for 반복문

`for` 문은 주어진 순서형 데이터(시퀀스)를 순회한다.

```python
my_list = [1, 2, 3]
for num in my_list:
    print(num)
# 1, 2, 3 출력
```

`range` 함수를 사용하면 숫자 시퀀스를 순회할 수 있다. `range` 함수는 지정된 범위의 숫자가 담긴 시퀀스를 반환하며, 0부터 시작한다. (Python 2의 `range`는 리스트를, `xrange`는 더 효율적인 이터레이터를 반환했으나, Python 3의 `range`는 `xrange`처럼 동작한다.)

```python
# 0, 1, 2, 3, 4 출력
for i in range(5):
    print(i)

# 2, 3, 4 출력
for i in range(2, 5):
    print(i)

# 2, 4, 6 출력
for i in range(2, 8, 2):
    print(i)
```

## while 반복문

`while` 문은 조건이 참인 동안 반복 실행된다.

```python
# 0, 1, 2, 3, 4 출력
count = 0
while count < 5:
    print(count)
    count += 1  # count = count + 1 과 동일하다.
```

## 점프문 (break, continue)

`break`는 반복문을 완전히 빠져나올 때, `continue`는 현재 반복을 건너뛰고 다음 반복으로 넘어갈 때 사용한다.

```python
# 0, 1, 2, 3, 4 출력
count = 0
while True:
    print(count)
    count += 1
    if count >= 5:
        break

# 홀수만 출력 - 1, 3, 5, 7, 9
for x in range(10):
    if x % 2 == 0:
        continue
    print(x)
```

## else 블록

C나 C++ 언어와 달리 Python에서는 반복문 뒤에 `else` 블록을 사용할 수 있다. 반복문의 조건이 거짓이 되어 정상 종료될 때 `else` 블록이 실행된다. 단, `break`문에 의해 반복문이 강제 종료되면 `else` 블록은 실행되지 않으며, `continue`문에 의해서는 `else` 블록이 정상적으로 실행된다.

```python
# 0, 1, 2, 3, 4 를 출력한 후 "count value reached 5" 출력
count = 0
while count < 5:
    print(count)
    count += 1
else:
    print("count value reached %d" % (count))

# 1, 2, 3, 4 출력
for i in range(1, 10):
    if i % 5 == 0:
        break
    print(i)
else:
    print("이 문장은 출력되지 않는다. 조건이 거짓이 되어서가 아니라 break로 인해 for문이 종료되었기 때문이다.")
```
