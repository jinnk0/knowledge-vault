[[Python/Python.md|Python]]의 숫자(Number) 자료형.

## 정수 (Integer)

정수는 변수에 정수값을 대입해 정의한다.

```python
my_int = 11
```

## 부동소수점 (Floating Point)

부동소수점 수는 소수점을 포함해 표기하거나, `float()` 함수를 사용해 정의할 수 있다.

```python
my_float = 11.0
# 아래와 같은 문법도 사용할 수 있다
my_float = float(11)
```
