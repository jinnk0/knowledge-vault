[[Python/Python.md|Python]]의 산술 연산자.

## 숫자 연산자

다른 언어와 마찬가지로 [[Python/숫자.md|숫자]]에는 덧셈, 뺄셈, 곱셈, 나눗셈 연산자를 사용할 수 있으며, 연산자 우선순위도 다른 언어와 유사하다.

```python
number = 4 + 2 * 6 - 4 / 2
print(number) # 14 출력
```

나눗셈에는 정수 나눗셈(Integer Division)과 실수 나눗셈(Float Division) 두 가지가 있다.

### 정수 나눗셈

정수 나눗셈은 나눗셈 결과의 내림값(Floor)을 반환한다. 즉 소수점 이하 값은 버려진다. Python 3에서는 `//` 연산자를 사용한다.

```python
print(4 // 3) # 1 출력
```

Python 2에는 원래 `//` 연산자가 없어 `__future__` 모듈에서 가져와야 하며, `/` 연산자는 피연산자가 모두 정수이면 정수 나눗셈으로 동작한다.

```python
from __future__ import division
print 4 // 3  # 1 출력
# 또는
print 4 / 3   # 1 출력
```

### 실수 나눗셈

실수 나눗셈은 나눗셈 결과의 부동소수점 근사값을 반환한다. 소수점 이하로 저장 가능한 자릿수가 제한되어 있어 부동소수점 수의 정확한 이진 표현을 저장하지 못하는 경우가 있고, 이 때문에 숫자를 비교하거나 반올림할 때 문제가 생기기도 한다.

Python 3에서는 `/` 연산자가 항상 실수 나눗셈을 수행한다.

```python
print(4 / 3) # 1.3333333333333333 출력
```

Python 2에서 `/`는 두 값이 모두 정수이면 정수 결과를, 하나라도 실수면 실수 결과를 반환한다. `__future__` 모듈을 가져오면 Python 3와 동일하게 `/`가 항상 실수 나눗셈을 수행하도록 만들 수 있다.

```python
from __future__ import division
print 4 / 3   # 1.33333333333 출력
# 또는, __future__ 없이 강제로 float 결과를 얻으려면 피연산자 중 하나를 float로 쓴다
print 4 / 3.0 # 1.33333333333 출력
```

### 기타 연산자

나머지 연산자(`%`)와 거듭제곱 연산자(`**`)도 사용할 수 있다.

```python
remainder = 10 % 4
print(remainder) # 2 출력

power = 2 ** 4
print(power) # 16 출력
```

[[Python/숫자.md|숫자]]와 [[Python/문자열.md|문자열]] 사이에는 산술 연산자를 사용할 수 없다. 예를 들어 정수와 문자열을 `+`로 더하면 오류가 발생한다.

```python
my_int = 11
my_string = "InterviewBit"
my_intstring = my_int + my_string  # 오류 발생
```

## 문자열 연산자

- 덧셈 연산자(`+`)를 사용하여 [[Python/문자열.md|문자열]]을 서로 연결(concatenation)할 수 있다.

```python
my_string = "Hello" + " " + "InterviewBit"
```

- 문자열에 숫자를 곱하면(`*`) 그 문자열이 반복되는 새 문자열을 만들 수 있다.

```python
my_string = "InterviewBit" * 5
```
