[[Python/Python.md|Python]]의 예외 처리(Exception Handling). 프로그래밍을 하다 보면 에러는 항상 발생하기 마련이다. 파이썬은 이런 상황에 대한 해결책으로 예외(Exception)를 사용하는데, 실행 중에 감지되는 에러를 예외라고 부른다.

## ZeroDivisionError

나눗셈이나 나머지 연산(modulo)에서 두 번째 인자(나누는 수)가 0일 때 발생한다.

```python
a = 1
b = 0
print(a / b)
# ZeroDivisionError: integer division or modulo by zero
```

## ValueError

내장 연산이나 함수가 올바른 자료형(type)의 값을 받았지만, 그 안에 적절하지 않은 값(value)이 담겨 있을 때 발생한다.

```python
a = "1"
b = "#"
print(int(a) / int(b))
# ValueError: invalid literal for int() with base 10: '#'
```

## 예외 처리하기 (Handling Exceptions)

`try`와 `except` 문을 사용해 특정 예외를 처리할 수 있다. 하나의 `try` 문은 둘 이상의 `except` 절을 가져 여러 예외를 처리할 수 있다.

```python
try:
    print(1 / 0)
except ZeroDivisionError as e:
    print("Error Code:", e)

# 출력 결과: Error Code: integer division or modulo by zero
```
