[[Python/Python.md|Python]]의 입력과 출력.

[[Python/Python.md|Python]] 2와 Python 3는 입출력 방식에 차이가 있다. 입력을 받을 때 Python 2에서는 `raw_input()`을, Python 3에서는 `input()`을 사용한다. 또한 Python 2에서 `print`문은 함수가 아니므로 괄호 없이 사용하지만, Python 3에서는 함수이므로 반드시 괄호와 함께 호출해야 한다.

```python
x = input()
print(x)
```
