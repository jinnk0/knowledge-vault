[[Python/자료형/자료형.md|자료형]] 중 문자열(String).

## 정의

문자열은 작은따옴표(`'`)나 큰따옴표(`"`)로 정의한다.

```python
my_string = 'InterviewBit'
my_string = "InterviewBit"
```

두 방식의 차이는, 큰따옴표를 쓰면 문자열 안에 아포스트로피(작은따옴표)를 쉽게 포함할 수 있다는 점이다. 작은따옴표로 문자열을 정의한 상태에서 아포스트로피를 넣으면 문자열이 그 지점에서 끝난 것으로 처리된다.

```python
my_string = "Don't worry about it"
```

## 포맷팅

[[Python/Python.md|Python]]은 C 언어 스타일의 문자열 포맷팅을 지원한다. `%` [[Python/연산자.md|연산자]]는 포맷 문자열(일반 텍스트와 `%s`, `%d` 같은 인자 지정자가 포함된 문자열)과 [[Python/자료형/컬렉션/튜플.md|튜플]]로 묶인 변수 집합을 포맷팅하는 데 사용한다.

```python
my_string = "InterviewBit"
print("Hello %s" % my_string)
# 출력: "Hello InterviewBit"
```

인자 지정자가 두 개 이상이면 튜플을 사용한다.

```python
qty = 10
item_name = "chocolate"
rs = 100
print("You can buy %d %s in %d rupees" % (qty, item_name, rs))
# 출력: "You can buy 10 chocolate in 100 rupees"
```

문자열이 아닌 객체도 `%s`로 포맷팅할 수 있다. 이때 해당 객체의 `str` 메서드가 반환하는 문자열이 삽입된다. (`repr` 메서드가 반환하는 문자열을 삽입하려면 `%r`을 쓴다.)

기본 인자 지정자:

- `%s`: 문자열(또는 문자열 표현을 가진 모든 객체)
- `%d`: 정수
- `%f`: 부동 소수점 숫자
- `%.<숫자>f`: 소수점 아래 자릿수가 고정된 부동 소수점 숫자
- `%x` / `%X`: 16진수 표현의 정수(소문자/대문자)

### format() 메서드

`format()` 메서드는 지정된 값을 문자열의 중괄호 `{}` 자리 표시자에 삽입해 새 문자열을 반환한다. 자리 표시자는 이름 지정 인덱스(`{price}`), 숫자 인덱스(`{0}`), 빈 자리 표시자(`{}`) 중 하나를 쓸 수 있다.

```python
qty = 10
item_name = "chocolate"
rs = 100

# 이름 지정 인덱스
print("You can buy {quantity} {item} in {amt} rupees".format(quantity=qty, item=item_name, amt=rs))

# 숫자 인덱스
print("You can buy {0} {1} in {2} rupees".format(qty, item_name, rs))

# 빈 자리 표시자
print("You can buy {} {} in {} rupees".format(qty, item_name, rs))
# 모두 출력: "You can buy 10 chocolate in 100 rupees"
```

### f-strings

PEP 498에서 도입된 **Literal String Interpolation** 메커니즘으로, 문자열 리터럴 앞에 `f`를 붙여서 만든다. `str.format()`과 비슷하게 동작하지만 문자열 리터럴 안에 직접 Python 표현식을 넣을 수 있어 더 간결하다.

```python
name = 'Tushar'
age = 23
print(f"Hello, My name is {name} and I'm {age} years old.")
# 출력: Hello, My name is Tushar and I'm 23 years old.
```

f-strings는 가장 널리 쓰이는 두 포맷팅 방식인 `%` 포맷팅, `str.format()`보다 실행 속도가 빠르다. (출처: [Real Python - F-Strings Speed Considerations & Performance](https://realpython.com/lessons/f-strings-speed-considerations-performance/))

## 연산

```python
my_string = "Hello InterviewBit"
print(len(my_string)) # 18 출력
```

`len()`으로 길이를 구한다.

```python
my_string = "Hello InterviewBit"
print(my_string.index("l"))
# 2 출력
```

`index()`는 지정한 문자가 처음 나타나는 인덱스를 반환한다. 문자가 여러 번 나오더라도 첫 번째 위치만 반환한다.

```python
my_string = "Hello InterviewBit"
print(my_string.count("e"))
# 3 출력
```

`count()`는 문자열 내 특정 문자의 개수를 센다.

```python
my_string = "Hello InterviewBit"
print(my_string[2:7])
# "llo I" 출력
```

슬라이싱으로 문자열의 일부를 잘라낼 수 있다. 인덱스 2부터 시작해 인덱스 6에서 끝난다.

```python
my_string = "Hello InterviewBit"
print(my_string[2:7:2])
# "loI" 출력
```

확장 슬라이스 구문 `[start:stop:step]`을 사용하면 한 칸씩 건너뛰며 잘라낼 수 있다.

## 검증

Python은 문자열이 알파벳으로만 구성되었는지, 영문자/숫자 혼용(alphanumeric)인지, 숫자인지 등을 확인하는 내장 검증 메서드를 제공한다.

- `str.isalnum()`: 모든 문자가 영문자 또는 숫자인지(`a-z`, `A-Z`, `0-9`) 확인한다.
- `str.isalpha()`: 모든 문자가 알파벳인지(`a-z`, `A-Z`) 확인한다.
- `str.isdigit()`: 모든 문자가 숫자인지(`0-9`) 확인한다.
- `str.islower()`: 알파벳 문자가 모두 소문자인지(`a-z`) 확인한다.
- `str.isupper()`: 알파벳 문자가 모두 대문자인지(`A-Z`) 확인한다.

```python
print('ab123'.isalnum())   # True
print('ab123#'.isalnum())  # False

print('abcD'.isalpha())    # True
print('abcd1'.isalpha())   # False

print('1234'.isdigit())    # True
print('123edsd'.isdigit()) # False

print('abcd123#'.islower()) # True
print('Abcd123#'.islower()) # False

print('ABCD123#'.isupper()) # True
print('Abcd123#'.isupper()) # False
```
