[[Python/자료형/컬렉션/컬렉션.md|컬렉션]]의 딕셔너리(Dictionary). 순서가 있고 변경 가능하며 인덱스(키)가 있다. 중괄호 `{}` 안에 키(key)와 값(value) 쌍으로 작성한다.

```python
my_dict = {1: 'Robin', 2: 'Rahul', 3: 'Aman'}
print(my_dict)

# 타입이 다른 키도 함께 쓸 수 있다.
my_dict = {'One': 'Robin', 2: 'Rahul'}
print(my_dict)
```

## 요소 접근

대괄호 `[]`에 키를 지정하거나, `get()` 메서드를 쓴다.

```python
my_dict = {1: 'Robin', 2: 'Rahul', 3: 'Aman'}
val = my_dict[2]
print(val) # 'Rahul'

val = my_dict.get(2)
print(val) # 'Rahul'
```

## 값 변경

키를 지정해 값을 바꿀 수 있다.

```python
my_dict = {1: 'Robin', 2: 'Rahul', 3: 'Aman'}
my_dict[2] = 'Rohan'
val = my_dict[2]
print(val) # 'Rohan'
```

## 순회

`for`문으로 순회하면 기본적으로 키(key)가 반환된다.

```python
my_dict = {1: 'Robin', 2: 'Rahul', 3: 'Aman'}

# 키 순회
for x in my_dict:
    print(x)    # 1 2 3

# values()로 값 순회
for x in my_dict.values():
    print(x)    # 'Robin' 'Rahul' 'Aman'

# items()로 키와 값을 함께 순회
for key, val in my_dict.items():
    print(key, val)
```

## 요소 추가

새 키에 값을 할당하면 항목이 추가된다.

```python
my_dict = {1: 'Robin', 2: 'Rahul', 3: 'Aman'}
my_dict[4] = 'Shivam'
print(my_dict)
```

## 요소 제거

- `pop()`: 지정한 키의 항목을 제거한다.
- `del`: 지정한 키의 항목을 제거한다.

```python
my_dict = {1: 'Robin', 2: 'Rahul', 3: 'Aman'}
my_dict.pop(2)
print(my_dict)

my_dict = {1: 'Robin', 2: 'Rahul', 3: 'Aman'}
del my_dict[2]
print(my_dict)
```

## dict() 생성자

`dict()` 생성자로도 딕셔너리를 만들 수 있다. 이때 키는 문자열 식별자여야 하며, 콜론(`:`) 대신 등호(`=`)를 쓴다.

```python
my_dict = dict(one='Robin', two='Rahul', three='Aman')
print(my_dict)
```
