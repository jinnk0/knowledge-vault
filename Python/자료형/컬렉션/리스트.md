[[Python/자료형/컬렉션/컬렉션.md|컬렉션]]의 리스트(List). [[NumPy/배열.md|배열]]과 유사하며, 임의의 타입의 값을 원하는 만큼 담을 수 있다. 순서가 있고 변경 가능하며, 중복 요소를 허용한다.

```python
my_list = []
# append는 리스트의 끝에 요소를 추가한다.
my_list.append(1)
my_list.append(2)
my_list.append(3)
print(my_list[0]) # 1
print(my_list[1]) # 2
print(my_list[2]) # 3
```

존재하지 않는 인덱스에 접근하면 예외가 발생한다.

```python
my_list = [1, 2, 3]
print(my_list[5]) # 오류 발생
```

## 음수 인덱싱

음수 인덱싱은 끝에서부터 접근한다. `-1`은 마지막 항목, `-2`는 뒤에서 두 번째 항목이다.

```python
my_list = [1, 2, 3]
print(my_list[-1]) # 3
print(my_list[-2]) # 2
```

## 중첩 리스트

리스트는 다른 리스트를 요소로 포함할 수 있고, 그 하위 리스트도 또 다른 리스트를 포함할 수 있다. 이를 중첩 리스트(Nested List)라 하며, 데이터를 계층적으로 정리할 때 쓴다.

```python
my_list = ['a', 'b', ['cc', 'dd', ['eee', 'fff']], 'g', 'h']

print(my_list[2])
# ['cc', 'dd', ['eee', 'fff']]

print(my_list[2][2])
# ['eee', 'fff']

print(my_list[2][2][0])
# 'eee'
```

### 요소 추가

- 끝에 값을 추가하려면 `append()`
- 특정 위치에 삽입하려면 `insert()`
- 다른 리스트를 병합하려면 `extend()`

```python
# append()
my_list = ['a', ['bb', 'cc'], 'd']
my_list[1].append('xx')
print(my_list) # ['a', ['bb', 'cc', 'xx'], 'd']

# insert()
my_list = ['a', ['bb', 'cc'], 'd']
my_list[1].insert(0, 'xx')
print(my_list) # ['a', ['xx', 'bb', 'cc'], 'd']

# extend()
my_list = ['a', ['bb', 'cc'], 'd']
my_list[1].extend([1, 2, 3])
print(my_list) # ['a', ['bb', 'cc', 1, 2, 3], 'd']
```

### 요소 제거

- 인덱스를 알고 있다면 `pop()`을 쓴다. 리스트를 수정하고 제거된 항목을 반환한다.
- 값만 알고 위치를 모른다면 `remove()`를 쓴다.

```python
# pop()
my_list = ['a', ['bb', 'cc', 'dd'], 'e']
x = my_list[1].pop(1)
print(my_list) # ['a', ['bb', 'dd'], 'e']
print(x)       # 'cc'

# remove()
my_list = ['a', ['bb', 'cc', 'dd'], 'e']
my_list[1].remove('cc')
print(my_list) # ['a', ['bb', 'dd'], 'e']
```

## 리스트 컴프리헨션

리스트 컴프리헨션(List Comprehension)은 기존 리스트를 바탕으로 한 줄로 새 리스트를 만드는 문법이다. 예를 들어 [[Python/자료형/문자열.md|문자열]]의 문자를 하나씩 리스트에 담는 작업을 `for` 루프로 하면 다음과 같다.

```python
S = 'InterviewBit'
letter_S = []
for l in S:
    letter_S.append(l)
print(letter_S)
```

리스트 컴프리헨션으로는 다음처럼 줄인다.

```python
S = 'InterviewBit'
letter_S = [l for l in S]
print(letter_S)
```

`if`문으로 조건을 걸 수도 있다. 1부터 9까지 범위에서 홀수만 모은 예시다.

```python
my_list = [x for x in range(1, 10) if x % 2 == 1]
print(my_list)
```
