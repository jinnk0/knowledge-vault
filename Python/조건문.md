[[Python/Python.md|Python]]의 조건문. 프로그래밍 언어에서 의사 결정문(Decision making statement)은 조건에 따라 프로그램 실행 흐름을 다르게 만든다.

Python은 조건을 평가할 때 불리언(Boolean) 값을 사용한다. 표현식을 비교하거나 평가하면 `True` 또는 `False`가 반환된다.

```python
num = 10
print(num == 5)  # False 출력
print(num == 10) # True 출력
```

두 값을 비교하는 방법은 [[Python/연산자.md|비교 연산자]]를 참고한다.

## if

`if` 키워드로 조건문을 작성한다. 조건이 참이면 블록이 실행된다.

```python
x = 100
y = 200
if y > x:
    print("y is greater than x")
```

## elif

`elif`는 "앞선 조건이 참이 아니라면 이 조건을 시도하라"는 의미다.

```python
x = 100
y = 100
if x > y:
    print("x is greater than y")
elif x == y:
    print("x and y are equal")
```

## else

`else`는 앞선 조건들에 걸리지 않은 나머지 모든 경우를 처리한다.

```python
x = 200
y = 100
if y > x:
    print("y is greater than x")
elif x == y:
    print("x and y are equal")
else:
    print("x is greater than y")
```
