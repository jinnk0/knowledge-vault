[[Python/Python.md|Python]]은 객체 지향 프로그래밍 언어다. 거의 모든 것이 속성(property)과 메서드(method)를 가진 객체(Object)이며, 객체는 변수와 [[Python/함수.md|함수]]를 하나로 캡슐화한 것이다. 객체는 클래스(Class)로부터 변수와 함수를 물려받고, 클래스는 객체를 만들기 위한 청사진(템플릿) 역할을 한다.

`class` 키워드로 클래스를 정의한다.

```python
class my_class:
    my_var = "InterviewBit"
    def my_function(self):
        print("Welcome to " + self.my_var)

my_obj = my_class()
my_obj.my_function()
# 출력: Welcome to InterviewBit
```

`self` 매개변수는 클래스의 현재 인스턴스를 참조하며, 클래스에 속한 변수에 접근할 때 쓴다.

## `__init__()` 함수

`__init__()`은 클래스가 인스턴스화될 때 항상 실행되는 내장 함수다. 객체의 속성에 초기값을 할당하거나 객체 생성 시 필요한 작업을 수행할 때 쓴다.

```python
class Student:
    def __init__(self, name, branch):
        self.name = name
        self.branch = branch

obj = Student("Robin", "CSE")
print(obj.name)
print(obj.branch)
```
