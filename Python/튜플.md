[[Python/Python.md|Python]]의 튜플(Tuple). 리스트와 유사하지만, 한번 생성되면 요소를 직접 변경할 수 없는 불변(immutable) 컬렉션이다.

## 파이썬 컬렉션

Python에는 4가지 컬렉션 데이터 타입이 있다.

- [[Python/리스트.md|리스트]]: 순서가 있고 변경 가능하다. 중복을 허용한다.
- 튜플: 순서가 있고 변경 불가능하다. 중복을 허용한다.
- [[Python/세트.md|세트]]: 순서가 없고 인덱스가 없다. 중복을 허용하지 않는다.
- [[Python/딕셔너리.md|딕셔너리]]: 순서가 있고 변경 가능하며 인덱스가 있다. 중복을 허용하지 않는다.

## 생성과 접근

```python
my_tuple = ('one', 'two', 'three')
print(my_tuple)
# ('one', 'two', 'three')

print(my_tuple[1])
# two
```

## 값 변경

튜플은 불변 객체라 생성 후 값을 바꿀 수 없다. 다만 리스트로 변환해 값을 바꾼 뒤 다시 튜플로 변환하는 우회 방법이 있다.

```python
my_tuple = ('one', 'two', 'three')
my_list = list(my_tuple)
my_list[2] = 'two'
my_tuple = tuple(my_list)
print(my_tuple)
# ('one', 'two', 'two')
```

## 단일 항목 튜플

항목이 하나뿐인 튜플을 만들려면 항목 뒤에 쉼표(`,`)를 붙여야 한다. 그렇지 않으면 튜플로 인식되지 않는다.

```python
# 튜플
my_tuple = ("one",)
print(type(my_tuple))

# 튜플이 아니라 문자열
my_tuple = ("one")
print(type(my_tuple))
```

## 튜플 결합

두 개 이상의 튜플은 `+` 연산자로 합칠 수 있다.

```python
my_tuple1 = ('one', 'two', 'three')
my_tuple2 = ('1', '2', '3')
my_tuple3 = my_tuple1 + my_tuple2
print(my_tuple3)
```
