정규 표현식(RegEx, Regular Expression)은 검색 패턴을 형성하는 문자열이다. 정규 표현식을 사용하면 어떤 [[Python/자료형/문자열.md|문자열]]에 지정된 검색 패턴이 포함되어 있는지 확인할 수 있다.

[[Python/표준 라이브러리/표준 라이브러리.md|표준 라이브러리]]에 속하는 모듈인 **re**는 정규 표현식을 다룰 수 있는 기능을 제공한다.

```python
# 문자열이 "The"로 시작하고 "India"로 끝나는지 확인
import re

txt = "The rain in India"
x = bool(re.search("^The.*India$", txt))
print(x)
# True 출력
```

## 주요 함수

`re` 모듈은 문자열에서 패턴과 일치하는 항목을 찾을 수 있도록 다양한 함수를 제공한다.

### `findall()`

일치하는 모든 항목이 담긴 리스트를 반환한다. 일치하는 항목이 없으면 빈 리스트가 반환된다.

```python
import re

txt = "The rain in India"
x = re.findall("in", txt)
print(x)
# ['in', 'in'] 출력
```

### `search()`

문자열에서 패턴과 일치하는 항목을 검색해, 있으면 `Match` 객체를 반환한다. 일치하는 항목이 둘 이상이어도 첫 번째로 일치한 항목만 반환하며, 없으면 `None`이 반환된다.

```python
# 문자열에서 첫 번째 공백 문자의 위치 검색
import re

txt = "The rain in India"
x = re.search("\s", txt)

print("The first white-space character is located in position:", x.start())
# "The first white-space character is located in position: 3" 출력
```

### `split()`

패턴과 일치하는 위치마다 문자열을 분할해 리스트로 반환한다.

```python
# 모든 공백 문자를 기준으로 분할
import re

txt = "The rain in India"
x = re.split("\s", txt)
print(x)
# ['The', 'rain', 'in', 'India'] 출력
```

`maxsplit` 매개변수를 지정하면 분할 횟수를 제어할 수 있다.

```python
# 첫 번째 공백에서만 문자열 분할
import re

txt = "The rain in India"
x = re.split("\s", txt, 1)
print(x)
# ['The', 'rain in India'] 출력
```

### `sub()`

일치하는 항목을 원하는 텍스트로 치환한다.

```python
# 모든 공백 문자를 숫자 9로 치환
import re

txt = "The rain in India"
x = re.sub("\s", "9", txt)
print(x)
# The9rain9in9India 출력
```

`count` 매개변수를 지정하면 치환할 횟수를 제어할 수 있다.

```python
import re

txt = "The rain in India"
x = re.sub("\s", "9", txt, 2)
print(x)
# The9rain9in India 출력
```
