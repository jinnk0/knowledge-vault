[[Python/Python.md|Python]]의 함수. 함수는 단일 동작을 수행하는 재사용 가능한 코드 블록이며, 애플리케이션의 [[클린 코드/코드 품질/모듈화.md|모듈성]]과 코드 [[클린 코드/코드 품질/재사용성과 일반화성.md|재사용성]]을 높여준다.

## 함수 정의하기

`def` 키워드 뒤에 함수 이름과 괄호를 붙여 정의한다.

```python
def my_function():
    print("Hello InterviewBit")
```

매개변수(parameter)는 괄호 안에 정의한다.

```python
def my_function(name):
    print("Hello %s" % name)
```

`return` 키워드로 호출한 곳에 값을 반환할 수 있다.

```python
def add_numbers(x, y):
    return x + y
```

## 함수 호출하기

함수 이름 뒤에 `()`를 쓰고 필요한 인자를 괄호 안에 전달한다.

```python
def my_function():
    print("Hello InterviewBit")

def add_numbers(x, y):
    return x + y

# "Hello InterviewBit" 출력
my_function()

val = add_numbers(2, 3)
print(val)
# 5 출력
```

## 키워드 인자를 갖는 함수

기본값(default value)이 설정된 인자를 키워드 인자(keyword argument)라 하고, 필수 입력 인자를 위치 인자(positional argument)라고 한다.

위치 인자는 항상 먼저 배치되어야 하며, 키워드 인자는 그 뒤에 따라와야 한다. 즉, 모든 필수 위치 인자가 앞에 오고, 선택적인 키워드 인자가 뒤에 위치한다.

기본값이 없는 인자는 필수 입력 항목이며, 누락될 경우 문법 오류(SyntaxError)가 발생한다.

```python
def greet(name, greeting="Hello"):
    print(f"{greeting}, {name}!")

greet("Tushar")                      # "Hello, Tushar!" 출력 (greeting은 기본값 사용)
greet("Tushar", "Hi")                # "Hi, Tushar!" 출력
greet(name="Tushar", greeting="Hi")  # 이름을 지정해서 전달할 수도 있다
```

## 함수형 프로그래밍

`map`, `filter`, `lambda`, `reduce`는 함수형 프로그래밍(functional programming) 패러다임에 속하는 도구다. 이 도구들을 쓰면 [[Python/제어문/반복문.md|반복문]]이나 [[Python/제어문/조건문.md|조건문]] 같은 절차를 직접 작성하지 않고도 더 단순하고 짧은 코드를 작성할 수 있다.

### 람다

람다(lambda)는 한 줄의 표현식으로 이루어진 익명 함수로, 주로 인라인 함수로 쓰인다. 몸체(body)가 단 한 줄인 함수라고 보면 된다. 함수형 프로그래밍과 GUI 프로그래밍에서 특히 유용하다.

```python
sum = lambda a, b, c: a + b + c
print(sum(1, 2, 3))
# 6 출력
```

### map()

`map(function, iterables)`은 반복 가능한 객체(iterable)의 각 항목에 지정된 함수를 실행하고, 그 결과를 모아 반환한다. 각 항목은 함수의 인자로 전달된다.

예를 들어 이름 목록이 주어졌을 때 각 이름의 길이를 담은 리스트를 만들려면 다음과 같이 작성한다.

```python
print(list(map(len, ['Tina', 'Raj', 'Tom'])))
# [4, 3, 3] 출력
```

### filter()

`filter(func, iterable)`은 `map()`과 달리 불리언 값(참 또는 거짓)을 반환하는 함수를 받아, 반복 가능한 객체의 요소 중 함수가 참을 반환하는 항목만 걸러낸다.

다음은 시험을 본 학생 10명의 점수 리스트에서, `filter`로 75점을 초과한 학생만 걸러내는 예시다.

```python
scores = [66, 90, 68, 59, 76, 60, 88, 74, 81, 65]

def is_A_student(score):
    return score > 75

over_75 = list(filter(is_A_student, scores))
print(over_75)
```

### reduce()

`reduce(func, iterable[, initial])`는 인자 2개를 받는 함수를 반복 가능한 객체의 요소에 누적적으로 적용하며, 초기값을 선택적으로 지정할 수 있다. 내장 함수가 아니라 `functools` 모듈에서 불러와야 한다.

예를 들어 리스트 `[1, 2, 3]`의 합은 다음과 같이 구한다.

```python
from functools import reduce
print(reduce(lambda x, y: x + y, [1, 2, 3]))
# 6 출력
```

초기값을 지정하면 그 값을 시작점으로 두고 줄여나간다. 리스트의 맨 앞에 초기값을 추가하는 것과 같다.

```python
from functools import reduce
print(reduce(lambda x, y: x + y, [1, 2, 3], -3))
# 3 출력

from math import gcd
print(reduce(gcd, [2, 4, 8], 3))
# 1 출력
```
