[[Python/Python.md|Python]]의 함수. 함수는 단일 동작을 수행하는 재사용 가능한 코드 블록이며, 애플리케이션의 모듈성과 코드 재사용성을 높여준다.

## 함수 정의하기

`def` 키워드 뒤에 함수 이름과 괄호를 붙여 정의한다.

```python
def my_function():
    print("Hello InterviewBit")
```

매개변수(parameter)는 괄호 안에 정의한다.

```python
def my_function(name):
    print("Hello %s" % name)
```

`return` 키워드로 호출한 곳에 값을 반환할 수 있다.

```python
def add_numbers(x, y):
    return x + y
```

## 함수 호출하기

함수 이름 뒤에 `()`를 쓰고 필요한 인자를 괄호 안에 전달한다.

```python
def my_function():
    print("Hello InterviewBit")

def add_numbers(x, y):
    return x + y

# "Hello InterviewBit" 출력
my_function()

val = add_numbers(2, 3)
print(val)
# 5 출력
```

## 키워드 인자를 갖는 함수

기본값(default value)이 설정된 인자를 키워드 인자(keyword argument)라 하고, 필수 입력 인자를 위치 인자(positional argument)라고 한다.

위치 인자는 항상 먼저 배치되어야 하며, 키워드 인자는 그 뒤에 따라와야 한다. 즉, 모든 필수 위치 인자가 앞에 오고, 선택적인 키워드 인자가 뒤에 위치한다.

기본값이 없는 인자는 필수 입력 항목이며, 누락될 경우 문법 오류(SyntaxError)가 발생한다.
