WHERE 절은 [[데이터베이스/SQL/SELECT/SELECT.md|SELECT]] 문에서 발췌 대상이 아닌 데이터를 제거해, 조건에 맞는 행만 남기는 절이다. FROM 절 다음에 위치한다.

## 조건식의 구성

WHERE 절의 조건식은 다음 요소로 구성된다.

- **컬럼(Column)명**: 보통 조건식의 좌측에 위치한다.
- **비교 연산자**: 좌측과 우측을 비교한다.
- **문자, 숫자, 표현식**: 보통 조건식의 우측에 위치한다.
- **비교 컬럼명**: [[데이터베이스/SQL/조인.md|JOIN]]을 사용할 때 우측에 다른 테이블의 컬럼이 온다.

```sql
SELECT 이름, 급여
FROM 사원
WHERE 급여 >= 3000;  -- 컬럼명, 비교 연산자, 숫자
```

## 부정 비교 연산자

"같지 않다", "크지 않다"처럼 조건을 부정할 때는 다음 연산자를 쓴다.

| 연산자 | 의미 |
|---|---|
| `!=` | 같지 않다. |
| `^=` | 같지 않다. |
| `<>` | 같지 않다. (ISO 표준, 모든 운영체제에서 사용 가능) |
| `NOT 컬럼명 =` | ~와 같지 않다. |
| `NOT 컬럼명 >` | ~보다 크지 않다. |

```sql
SELECT 이름 FROM 사원 WHERE 부서번호 <> 10;
SELECT 이름 FROM 사원 WHERE NOT 급여 > 3000;  -- 급여가 3000보다 크지 않은 사원
```

> 컬럼 값이 [[데이터베이스/NULL.md|NULL]]인 행은 어떤 비교 연산자로도 걸러낼 수 없다. NULL 여부는 IS NULL, IS NOT NULL로 확인한다.
