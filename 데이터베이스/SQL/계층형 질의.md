계층형 질의(Hierarchical Query)는 테이블에 계층형 데이터가 존재하는 경우 그 데이터를 조회하기 위해 사용하는 [[데이터베이스/SQL/SQL.md|SQL]] 질의다. 계층형 데이터란 동일 테이블에 계층적으로 상위와 하위 데이터가 포함된 데이터를 말한다. 사원 테이블에 각 사원의 관리자 사원번호가 함께 저장된 경우가 대표적이다.

| 사원번호 | 이름 | 관리자번호 |
|---|---|---|
| 1 | 김 | NULL |
| 2 | 이 | 1 |
| 3 | 박 | 1 |
| 4 | 최 | 2 |

계층형 질의를 작성하는 방법은 DBMS마다 다르다. Oracle은 전용 구문(START WITH, CONNECT BY, PRIOR)을 쓰고, SQL Server는 CTE를 재귀 호출한다.

## Oracle의 계층형 질의

```sql
SELECT LEVEL, 사원번호, 이름, 관리자번호
FROM 사원
START WITH 관리자번호 IS NULL           -- 루트 데이터: 관리자가 없는 김
CONNECT BY PRIOR 사원번호 = 관리자번호  -- 부모 → 자식 방향(순방향) 전개
ORDER SIBLINGS BY 이름;                 -- 같은 LEVEL의 형제끼리 정렬
```

계층형 질의는 다음 구문으로 구성된다.

- **START WITH 절**: 계층 구조 전개의 시작 위치를 지정하는 구문이다. 즉 루트 데이터를 지정한다(액세스).
- **CONNECT BY 절**: 다음에 전개될 자식 데이터를 지정하는 구문이다. 여기에 PRIOR 키워드를 써서 전개 방향을 정한다.
- **ORDER SIBLINGS BY**: 형제 노드(동일 LEVEL) 사이에서 정렬을 수행한다.

### PRIOR

PRIOR는 CONNECT BY 절에 사용되며, 현재 읽은 컬럼을 지정한다. PRIOR를 어느 쪽에 붙이느냐에 따라 전개 방향이 달라진다.

| 형태 | 전개 방향 | 이름 |
|---|---|---|
| `PRIOR 자식 = 부모` | 부모 데이터 → 자식 데이터 | 순방향 전개 |
| `PRIOR 부모 = 자식` | 자식 데이터 → 부모 데이터 | 역방향 전개 |

위 사원 테이블에서는 사원번호가 자식 쪽, 관리자번호가 부모 쪽 컬럼이다. 그래서 `CONNECT BY PRIOR 사원번호 = 관리자번호`는 방금 읽은 행의 사원번호를 관리자번호로 가진 행, 즉 부하 직원을 찾아 내려가는 순방향 전개다.

```sql
-- 역방향 전개: 최에서 출발해 관리자 방향으로 올라간다 (최 → 이 → 김)
SELECT 사원번호, 이름
FROM 사원
START WITH 이름 = '최'
CONNECT BY PRIOR 관리자번호 = 사원번호;
```

PRIOR 키워드는 CONNECT BY 절뿐만 아니라 SELECT 절, WHERE 절에서도 사용할 수 있다.

### WHERE 절의 역할

Oracle의 계층형 질의에서 [[데이터베이스/SQL/SELECT/WHERE 절.md|WHERE 절]]은 모든 전개를 진행한 이후에 적용되는 필터 조건으로, 조건을 만족하는 데이터만 추출하는 데 활용된다. 따라서 WHERE 절로 특정 행을 걸러내도 계층 전개 자체에는 영향을 주지 않는다.

## SQL Server의 계층형 질의

SQL Server의 계층형 질의는 CTE(Common Table Expression)를 재귀 호출함으로써 계층 구조를 전개한다. 먼저 앵커 멤버를 실행하여 기본 결과 집합을 만들고, 이후 재귀 멤버를 지속적으로 실행한다.

```sql
WITH 조직도 AS (
    -- 앵커 멤버: 기본 결과 집합(루트)
    SELECT 사원번호, 이름, 관리자번호, 1 AS 레벨
    FROM 사원
    WHERE 관리자번호 IS NULL
    UNION ALL
    -- 재귀 멤버: 직전 결과의 부하 직원을 찾아 계속 실행된다
    SELECT E.사원번호, E.이름, E.관리자번호, C.레벨 + 1
    FROM 사원 E
    JOIN 조직도 C ON E.관리자번호 = C.사원번호
)
SELECT * FROM 조직도;
```

계층형 데이터를 FROM 절에서 같은 테이블끼리 직접 연결해 조회할 때는 [[데이터베이스/SQL/조인.md|셀프 조인]]을 쓴다.
