순수 관계 연산자는 [[데이터베이스/SQL/관계 대수/관계 대수.md|관계 대수]] 연산자의 하나로, 관계형 [[데이터베이스/데이터베이스.md|데이터베이스]]에서 릴레이션(테이블)의 구조와 특성을 이용해 데이터를 처리하기 위해 특별히 개발된 관계대수 연산자다. SELECT, PROJECT, JOIN, DIVISION의 네 가지가 있으며, 각각 [[데이터베이스/SQL/SQL.md|SQL]]에서 다음과 같이 구현된다.

| 순수 관계 연산자 | 하는 일 | SQL에서의 구현 |
|---|---|---|
| SELECT (선택) | 조건을 만족하는 행을 고른다 | WHERE 절 |
| PROJECT (추출) | 지정한 열만 뽑는다 | SELECT 절 |
| (NATURAL) JOIN (조인) | 두 릴레이션을 결합한다 | 다양한 JOIN 기능 |
| DIVIDE (DIVISION, 디비전) | 모든 조건을 만족하는 데이터를 찾는다 | 현재 사용되지 않음 |

이름이 같아도 관계 연산자의 SELECT는 SQL의 SELECT 절이 아니라 WHERE 절에 대응하고, SQL의 SELECT 절에 대응하는 것은 PROJECT 연산이라는 점에 주의한다.

## SELECT (선택 연산자)

SELECT 연산은 릴레이션에서 주어진 조건을 만족하는 튜플(행)을 선택하여 부분집합을 구한다. 릴레이션의 가로(행)를 연산하므로 수평 연산이라고도 하며, SQL의 [[데이터베이스/SQL/SELECT/WHERE 절.md|WHERE 절]]에 대응한다.

## PROJECT (추출 연산자)

PROJECT 연산은 릴레이션에서 지정된 속성(열)들만 추출하여 새로운 릴레이션을 만든다. 릴레이션의 세로(열)를 연산하므로 수직 연산이라고도 하며, SQL의 [[데이터베이스/SQL/SELECT/SELECT.md|SELECT 절]]에 대응한다.

PROJECT 연산의 결과에서는 중복되는 튜플이 자동으로 제거된다. 반면 SQL의 SELECT 절은 기본값이 ALL이라 중복을 그대로 출력하므로, 중복을 없애려면 DISTINCT를 붙여야 한다.

## JOIN (조인 연산자)

JOIN 연산은 공통 속성을 중심으로 2개의 릴레이션을 결합하여 하나의 새로운 릴레이션을 만든다. 결합하는 방식에 따라 다음과 같이 분류된다.

- **세타 조인(Theta Join)**: 비교 연산자를 활용해 조건을 만족하는 튜플을 결합한다. 모든 조인의 기본 형태다.
- **동등 조인(EQUI JOIN)**: 세타 조인 중 비교 연산자가 등호(`=`)인 경우다. 기준이 된 중복 속성이 결과에 그대로 남는다.
- **자연 조인(Natural Join)**: 동등 조인에서 중복된 속성을 제거하여 한 번만 표시하는 조인으로, 가장 널리 쓰인다. 별도 조건을 적지 않으면 이름이 같은 모든 속성을 기준으로 결합한다.
- **외부 조인(Outer Join)**: 조인 조건에 맞지 않아 버려지는 튜플도 모두 결과에 포함하고, 값이 없는 부분은 [[데이터베이스/NULL.md|NULL]]로 채운다. Left, Right, Full 외부 조인으로 구분된다.

세타 조인이 가장 넓은 개념이고, 그중 등호만 쓰는 것이 동등 조인, 동등 조인에서 중복 속성을 없앤 것이 자연 조인이다. SQL에서는 동등 조인이 EQUI JOIN, 등호 외의 비교 연산자를 쓰는 세타 조인이 NON EQUI JOIN, 자연 조인이 NATURAL JOIN, 외부 조인이 OUTER JOIN으로 구현된다. 각각의 SQL 문법은 [[데이터베이스/SQL/조인.md|조인]] 노트에서 다룬다.

## DIVISION (디비전 연산자)

DIVISION 연산은 '모든 조건을 만족하는' 데이터를 찾을 때 주로 사용한다. 나누어지는 릴레이션에서, 나누는 릴레이션의 모든 속성값과 관련 있는 튜플만 추출한다.

예를 들어 수강(학생, 과목) 릴레이션을 필수과목(과목) 릴레이션으로 나누면, 필수과목에 있는 모든 과목을 수강한 학생만 결과로 남는다. SQL에는 이 연산을 직접 수행하는 문법이 없다.
