조인(JOIN)은 두 개 이상의 테이블을 연결 또는 결합하여 데이터를 출력하는 [[데이터베이스/SQL/SQL.md|SQL]] 기능이다. 일반적인 경우 행들은 PRIMARY KEY(PK)나 FOREIGN KEY(FK) 값의 연관에 의해 조인이 성립된다. 하지만 어떤 경우에는 이러한 PK, FK의 관계가 없어도 논리적인 값들의 연관만으로 조인이 성립된다.

FROM 절에 여러 테이블이 나열되어 있어도, DBMS 옵티마이저는 테이블이 아무리 많아도 항상 2개의 테이블씩 짝을 지어 JOIN을 수행한다. 예를 들어 A, B, C 세 테이블을 조인하면 먼저 두 테이블을 조인하고, 그 결과와 나머지 한 테이블을 다시 조인한다.

[[데이터베이스/데이터 모델링/키.md|키]]와 [[데이터베이스/데이터 모델링/식별자.md|식별자]] 상속의 관점에서 조인이 엔터티 간 관계와 어떻게 연결되는지는 [[데이터베이스/데이터 모델링/관계.md|관계]] 노트에서 다룬다. 관계대수 관점에서 조인을 세타 조인, 동등 조인, 자연 조인, 외부 조인으로 나누는 분류는 [[데이터베이스/SQL/순수 관계 연산자.md|순수 관계 연산자]] 노트에서 다룬다.

## EQUI JOIN

EQUI JOIN은 조인에 관여하는 테이블 간의 컬럼 값들이 정확하게 일치하는 경우에 사용하는 방법이다. `=` 연산자에 의해서만 수행되며, 그 밖의 비교 연산자를 사용하는 조인은 모두 NON EQUI JOIN이다.

EQUI JOIN은 조인 조건을 어디에 쓰느냐에 따라 두 가지 방식으로 작성할 수 있다.

```sql
-- WHERE 절에 JOIN 조건을 넣는다
SELECT 테이블1.컬럼명, 테이블2.컬럼명
FROM 테이블1, 테이블2
WHERE 테이블1.컬럼명 = 테이블2.컬럼명;

-- ANSI/ISO SQL 표준: ON 절에 JOIN 조건을 넣는다
SELECT 테이블1.컬럼명, 테이블2.컬럼명
FROM 테이블1 INNER JOIN 테이블2
ON 테이블1.컬럼명1 = 테이블2.컬럼명2;
```

## NON EQUI JOIN

NON EQUI JOIN은 두 테이블의 컬럼 값이 정확하게 일치하지 않을 때, `=`이 아닌 다른 비교 연산자(BETWEEN, >, >=, <, <= 등)로 조인하는 방법이다. 대부분 NON EQUI JOIN을 수행할 수 있지만, 때로는 설계상의 이유로 수행이 불가능한 경우도 있다.

급여가 어느 등급 구간에 속하는지 찾는 경우처럼, 한 테이블의 값이 다른 테이블의 범위 안에 들어가는지를 조건으로 삼을 때 쓴다.

```sql
SELECT 사원.이름, 사원.급여, 급여등급.등급
FROM 사원, 급여등급
WHERE 사원.급여 BETWEEN 급여등급.최저급여 AND 급여등급.최고급여;
```

## ANSI/ISO SQL의 JOIN 형태

ANSI/ISO SQL에서는 FROM 절에 다음과 같은 JOIN 형태를 표시한다.

- INNER JOIN
- NATURAL JOIN
- USING 조건절
- ON 조건절
- CROSS JOIN
- OUTER JOIN (LEFT, RIGHT, FULL)

아래 설명에서는 다음 두 테이블을 예로 든다. 사원 박은 부서번호가 NULL이고, 부서 30(인사)에는 소속 사원이 없다.

| 사원.이름 | 사원.부서번호 |
|---|---|
| 김 | 10 |
| 이 | 20 |
| 박 | NULL |

| 부서.부서번호 | 부서.부서명 |
|---|---|
| 10 | 영업 |
| 20 | 개발 |
| 30 | 인사 |

### INNER JOIN

INNER JOIN은 OUTER(외부) JOIN과 대비하여 내부 JOIN이라고 하며, JOIN 조건에서 동일한 값이 있는 행만 반환한다. 양쪽 테이블 모두에 해당 값이 존재해야만 반환된다.

```sql
SELECT 사원.이름, 부서.부서명
FROM 사원 INNER JOIN 부서
ON 사원.부서번호 = 부서.부서번호;
-- 결과: (김, 영업), (이, 개발) → 2건
```

### CROSS JOIN

CROSS JOIN은 테이블 간 JOIN 조건이 없는 경우 생길 수 있는 모든 데이터의 조합을 말한다. 결과는 양쪽 집합의 M\*N 건의 데이터 조합이 발생한다.

```sql
SELECT 사원.이름, 부서.부서명
FROM 사원 CROSS JOIN 부서;
-- 결과: 사원 3건 × 부서 3건 = 9건
```

### OUTER JOIN

OUTER JOIN은 JOIN 조건에 맞는 값이 없는 행도 결과에 포함하며, 어느 테이블을 기준으로 삼느냐에 따라 LEFT, RIGHT, FULL로 나뉜다.

- **LEFT OUTER JOIN**: 조인 수행 시 먼저 표기된 좌측 테이블에 해당하는 데이터를 먼저 읽은 후, 나중 표기된 우측 테이블에서 JOIN 대상 데이터를 읽어 온다. 즉 Table A와 B가 있을 때 A가 기준이 된다. A와 B를 비교해서 B의 JOIN 컬럼에 같은 값이 있으면 그 데이터를 가져오고, 같은 값이 없으면 B 테이블에서 가져오는 컬럼들을 [[데이터베이스/NULL.md|NULL]] 값으로 채운다.
- **RIGHT OUTER JOIN**: LEFT OUTER JOIN과 반대로, 나중에 표기된 우측 테이블이 기준이 된다.
- **FULL OUTER JOIN**: 조인 수행 시 좌측, 우측 테이블의 모든 데이터를 읽어 JOIN하여 결과를 생성한다. 즉 A와 B가 모두 기준이 되며, LEFT OUTER JOIN과 RIGHT OUTER JOIN의 결과를 합집합으로 처리한 결과와 동일하다.

```sql
SELECT 사원.이름, 부서.부서명
FROM 사원 LEFT OUTER JOIN 부서
ON 사원.부서번호 = 부서.부서번호;
-- 결과: (김, 영업), (이, 개발), (박, NULL) → 3건

SELECT 사원.이름, 부서.부서명
FROM 사원 FULL OUTER JOIN 부서
ON 사원.부서번호 = 부서.부서번호;
-- 결과: (김, 영업), (이, 개발), (박, NULL), (NULL, 인사) → 4건
```

예시 테이블에 각 조인을 적용한 결과 건수를 비교하면 다음과 같다.

| 조인 | 결과 건수 | 이유 |
|---|---|---|
| INNER JOIN | 2 | 양쪽에 같은 부서번호가 있는 김, 이만 남는다 |
| LEFT OUTER JOIN | 3 | 사원은 모두 남고, 박의 부서명은 NULL로 채워진다 |
| FULL OUTER JOIN | 4 | LEFT 결과에 사원이 없는 부서 인사까지 더해진다 |
| CROSS JOIN | 9 | 조건 없이 3 × 3의 모든 조합이 만들어진다 |
