집합 연산자는 여러 개의 [[데이터베이스/SQL/SELECT/SELECT.md|SELECT]] 문의 결과를 하나로 합치거나, 공통 부분이나 차이를 구하는 [[데이터베이스/SQL/SQL.md|SQL]] 연산자다. 관계 대수의 [[데이터베이스/SQL/관계 대수/일반 집합 연산자.md|일반 집합 연산자]]를 SQL로 구현한 것이다.

## 종류

| 연산자 | 결과 | 중복 행 |
|---|---|---|
| UNION | 여러 SQL문 결과의 합집합 | 하나의 행으로 만든다 |
| UNION ALL | 여러 SQL문 결과의 합집합 | 그대로 표시한다 |
| INTERSECT | 여러 SQL문 결과의 교집합 | 하나의 행으로 만든다 |
| EXCEPT | 앞 SQL문 결과에서 뒤 SQL문 결과를 뺀 차집합 | 하나의 행으로 만든다 |

- **UNION**: 여러 개의 SQL문의 결과에 대한 합집합으로, 결과에서 모든 중복된 행은 하나의 행으로 만든다.
- **UNION ALL**: 여러 개의 SQL문의 결과에 대한 합집합이지만, 중복된 행도 그대로 결과로 표시된다. 즉 단순히 결과만 합쳐 놓은 것이다. 일반적으로 여러 질의 결과가 상호 배타적(Exclusive)일 때 많이 사용한다. 개별 SQL문의 결과가 서로 중복되지 않는 경우에는 UNION과 결과가 동일하다. 단, 결과의 정렬 순서에는 차이가 있을 수 있다.
- **INTERSECT**: 여러 개의 SQL문의 결과에 대한 교집합이다. 중복된 행은 하나의 행으로 만든다.
- **EXCEPT**: 앞의 SQL문의 결과에서 뒤의 SQL문의 결과를 뺀 차집합이다. 중복된 행은 하나의 행으로 만든다. Oracle 등 일부 데이터베이스는 MINUS를 사용한다.

## 예시

두 SELECT 문의 결과가 각각 {A, B, B, C}, {B, C, D}일 때 연산자별 결과는 다음과 같다.

```sql
SELECT 이름 FROM 서울지점    -- A, B, B, C
UNION                        -- 결과: A, B, C, D
SELECT 이름 FROM 부산지점;   -- B, C, D
```

| 연산자 | 결과 |
|---|---|
| UNION | A, B, C, D |
| UNION ALL | A, B, B, C, B, C, D |
| INTERSECT | B, C |
| EXCEPT (MINUS) | A |
