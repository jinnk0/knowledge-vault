단일행 함수는 각 행의 값을 입력받아 행마다 하나의 결과를 반환하는 [[데이터베이스/SQL/함수/함수.md|함수]]다. 입력하는 값의 타입에 따라 문자형, 숫자형, 날짜형, 변환형, NULL 관련 함수의 다섯 가지로 나뉜다.

Oracle과 SQL Server에서 이름이 다른 함수는 `Oracle 함수/SQL Server 함수` 순서로 표기한다. Oracle에서 테이블 없이 함수 결과만 확인할 때는 [[데이터베이스/SQL/SELECT/SELECT.md|DUAL 테이블]]을 쓴다.

```sql
SELECT UPPER('sql'), ROUND(3.14159, 2), SYSDATE FROM DUAL;
```

## 문자형 함수

문자형 함수는 문자를 입력하면 문자나 숫자 값을 반환한다.

| 함수 | 설명 | 예시 |
|---|---|---|
| LOWER(문자열) | 문자열의 알파벳 문자를 모두 소문자로 바꾼다. | LOWER('SQL Expert') → 'sql expert' |
| UPPER(문자열) | 문자열의 알파벳 문자를 모두 대문자로 바꾼다. | UPPER('SQL Expert') → 'SQL EXPERT' |
| INITCAP(문자열) | 단어마다 첫 글자만 대문자로, 나머지는 소문자로 바꾼다. Oracle 함수이며 SQL Server에는 없다. | INITCAP('sql expert') → 'Sql Expert' |
| SUBSTR/SUBSTRING(문자열, m[, n]) | 문자열 중 m 위치에서 n개의 문자 길이에 해당하는 문자를 돌려준다. n이 생략되면 마지막 문자까지 돌려준다. | SUBSTR('SQL Expert', 5, 3) → 'Exp' |
| LENGTH/LEN(문자열) | 문자열의 문자 개수를 숫자 값으로 돌려준다. | LENGTH('SQL Expert') → 10 |
| LTRIM(문자열[, 지정문자]) | 문자열의 첫 문자부터 확인해서 지정 문자가 나타나는 동안 해당 문자를 제거한다. 지정 문자를 생략하면 공백을 제거한다. | LTRIM('xxYYZZxYZ', 'x') → 'YYZZxYZ' |
| RTRIM(문자열[, 지정문자]) | 문자열의 마지막 문자부터 확인해서 지정 문자가 나타나는 동안 해당 문자를 제거한다. 지정 문자를 생략하면 공백을 제거한다. | RTRIM('XXYYzzXYzz', 'z') → 'XXYYzzXY' |
| TRIM([LEADING / TRAILING / BOTH] 지정문자 FROM 문자열) | 문자열의 머리말(LEADING), 꼬리말(TRAILING), 또는 양쪽(BOTH)에 있는 지정 문자를 제거한다. 방향을 생략하면 BOTH가 기본값이다. | TRIM('x' FROM 'xxYYZZxYZxx') → 'YYZZxYZ' |
| ASCII(문자) | 문자나 숫자를 ASCII 코드 번호로 바꾼다. | ASCII('A') → 65 |
| CHR/CHAR(ASCII 번호) | ASCII 코드 번호를 문자나 숫자로 바꾼다. ASCII 함수와 반대 방향의 변환이다. | CHR(65) → 'A' |
| CONCAT(문자열1, 문자열2) | 문자열1과 문자열2를 연결한다. | CONCAT('RDBMS', ' SQL') → 'RDBMS SQL' |
| LEFT/RIGHT(문자열, 개수) | 왼쪽 또는 오른쪽에서 지정한 개수만큼 문자를 추출한다. SQL Server 함수다. | LEFT('SQL Expert', 3) → 'SQL' |
| REPLACE(문자열, 찾을문자, 바꿀문자) | 특정 문자열을 찾아 다른 문자열로 통째로 치환한다. | REPLACE('SQL Expert', 'Expert', 'Pro') → 'SQL Pro' |
| TRANSLATE(문자열, 검색문자, 치환문자) | 검색문자의 각 문자를 같은 위치의 치환문자로 하나씩 바꾼다. | TRANSLATE('ABCD', 'AB', 'XY') → 'XYCD' |

몇몇 함수는 Oracle과 SQL Server에서 쓰는 방법이 다르다.

- **SUBSTRING**: SQL Server의 SUBSTRING(문자열, m, n)은 n을 생략할 수 없다.
- **LEN**: SQL Server의 LEN은 문자열 끝의 공백은 세지 않는다. (출처: Microsoft Learn)
- **LTRIM/RTRIM/TRIM**: Oracle의 LTRIM, RTRIM은 지정 문자를 여러 개 주면 그 집합에 속한 문자가 나오지 않을 때까지 계속 제거한다. SQL Server는 버전에 따라 지원 범위가 다르다. SQL Server 2019 이하에서는 LTRIM, RTRIM에 지정 문자를 쓸 수 없어 공백만 제거할 수 있고, TRIM은 2017부터 `TRIM(지정문자 FROM 문자열)` 형태를 지원한다. SQL Server 2022부터는 LTRIM, RTRIM에도 지정 문자를 쓸 수 있고, TRIM에 LEADING, TRAILING, BOTH를 지정할 수 있다. (출처: Microsoft Learn)
- **CONCAT**: Oracle, MySQL, SQL Server(2012 이상)에서 쓸 수 있다. Oracle의 CONCAT은 인자를 정확히 두 개만 받는다. 세 개 이상을 연결할 때는 합성 연산자를 쓰는데, Oracle은 `||`, SQL Server는 `+`다. SQL Server의 CONCAT은 두 개 이상의 인자를 받는다. (출처: Microsoft Learn)
- **LEFT/RIGHT**: Oracle에는 없으므로 SUBSTR로 같은 결과를 얻는다. 예를 들어 `SUBSTR('SQL Expert', -6)`은 `RIGHT('SQL Expert', 6)`과 같은 'Expert'를 반환한다.
- **REPLACE**: Oracle은 바꿀문자를 생략하면 찾을문자를 삭제한다.
- **TRANSLATE**: Oracle은 치환문자가 검색문자보다 짧으면 대응하는 치환문자가 없는 문자를 삭제한다. SQL Server는 2017부터 지원하며, 검색문자와 치환문자의 길이가 같아야 한다.

```sql
-- Oracle: 세 개 이상의 문자열 연결
SELECT 'RDBMS' || ' ' || 'SQL' FROM DUAL;
-- SQL Server
SELECT 'RDBMS' + ' ' + 'SQL';
```

## 숫자형 함수

숫자형 함수는 숫자를 입력하면 숫자 값을 반환한다.

| 함수 | 설명 | 예시 |
|---|---|---|
| ABS(숫자) | 숫자의 절댓값을 반환한다. | ABS(-15) → 15 |
| MOD(숫자1, 숫자2) | 숫자1을 숫자2로 나눈 나머지를 반환한다. SQL Server에서는 MOD 대신 % 연산자를 쓴다. | MOD(7, 3) → 1 |
| ROUND(숫자[, m]) | 소수점 아래 m자리까지 남기도록 반올림한다. m을 생략하면 정수로 반올림하고, m이 음수이면 정수부에서 반올림한다. | ROUND(38.5235, 3) → 38.524, ROUND(1234, -2) → 1200 |
| TRUNC(숫자[, m]) | 소수점 아래 m자리까지 남기고 나머지를 버린다. Oracle 함수이며, SQL Server에서는 ROUND(숫자, m, 1)처럼 세 번째 인자로 버림을 지정한다. | TRUNC(38.5235, 3) → 38.523 |
| SIGN(숫자) | 양수이면 1, 음수이면 -1, 0이면 0을 반환한다. | SIGN(-15) → -1 |
| CEIL/CEILING(숫자) | 올림. 주어진 숫자보다 크거나 같은 최소 정수를 반환한다. | CEIL(38.123) → 39, CEIL(-38.123) → -38 |
| FLOOR(숫자) | 내림. 주어진 숫자보다 작거나 같은 최대 정수를 반환한다. | FLOOR(38.123) → 38, FLOOR(-38.123) → -39 |
| EXP(n) | 자연상수 e의 n 제곱을 구한다. | EXP(1) → 2.71828... |
| LOG | 지정한 밑을 가진 로그 값을 구한다. | LOG(10, 100) → 2 (Oracle) |
| LN(숫자) | 자연로그(밑이 e인 로그) 값을 구한다. Oracle 함수다. | LN(EXP(1)) → 1 |
| POWER(m, n) | m의 n 제곱을 구한다. | POWER(2, 3) → 8 |
| SIN/COS/TAN(숫자) | 삼각함수 값을 구한다. 인자는 도(°)가 아니라 라디안 단위의 각도다. | SIN(0) → 0 |
| SQRT(숫자) | 제곱근을 구한다. 음수는 넣을 수 없다. | SQRT(16) → 4 |

숫자를 입력받아 문자를 돌려주는 CHR/CHAR는 ASCII와 짝을 이루므로 문자형 함수에서 함께 다룬다.

헷갈리기 쉬운 부분은 다음과 같다.

- **음수의 올림·내림·버림**: FLOOR는 음수에서 0에서 멀어지는 방향으로 내리므로, 소수점 아래를 잘라내기만 하는 TRUNC와 결과가 다르다. `FLOOR(-38.123)`은 -39이지만 `TRUNC(-38.123)`은 -38이다.
- **LOG의 인자 순서**: DBMS마다 다르다. Oracle은 `LOG(밑, 숫자)`다. SQL Server는 `LOG(숫자[, 밑])`이며, 밑을 생략하면 자연로그를 구한다. 그래서 SQL Server에는 LN이 없고 `LOG(숫자)`로 같은 값을 구한다. SQL Server에는 상용로그 함수 LOG10도 있다.
- **TRUNC와 날짜**: Oracle의 TRUNC는 날짜에도 쓸 수 있다. `TRUNC(SYSDATE)`는 시각을 버린 오늘 날짜를 반환한다.

## 날짜형 함수

날짜형 함수는 DATE 타입의 값을 연산한다.

| Oracle | SQL Server | 설명 |
|---|---|---|
| SYSDATE | GETDATE() | 현재 날짜와 시각을 반환한다. |
| EXTRACT(YEAR FROM d) | DATEPART(YEAR, d) | 날짜 값에서 연, 월, 일, 시, 분, 초 등 지정한 부분을 숫자로 추출한다. |
| TO_NUMBER(TO_CHAR(d, 'YYYY')) | YEAR(d) | 날짜에서 연, 월, 일을 뽑아 숫자로 반환한다. 월은 'MM'과 MONTH, 일은 'DD'와 DAY를 쓴다. |

Oracle은 TO_CHAR로 날짜에서 해당 부분을 문자열로 뽑은 뒤 TO_NUMBER로 숫자로 바꾸고, SQL Server는 YEAR, MONTH, DAY 함수로 바로 구한다. `YEAR(d)`는 `DATEPART(YEAR, d)`와 같다.

```sql
-- Oracle
SELECT SYSDATE,
       EXTRACT(MONTH FROM SYSDATE),
       TO_NUMBER(TO_CHAR(SYSDATE, 'MM'))
FROM DUAL;

-- SQL Server
SELECT GETDATE(),
       DATEPART(MONTH, GETDATE()),
       MONTH(GETDATE());
```

## 변환형 함수

변환형 함수는 문자, 숫자, 날짜형 값의 데이터 타입을 변환한다.

| 함수 | 설명 | 예시 |
|---|---|---|
| TO_NUMBER(문자열) | 문자열을 숫자로 변환한다. | TO_NUMBER('100') → 100 |
| TO_CHAR(숫자 또는 날짜, 형식) | 숫자나 날짜를 지정한 형식(FORMAT)의 문자열로 변환한다. | TO_CHAR(SYSDATE, 'YYYY-MM-DD') |
| TO_DATE/CAST | 문자열을 날짜형으로 변환한다. Oracle은 TO_DATE(문자열, 형식), SQL Server는 CAST(식 AS 데이터타입)을 쓴다. | TO_DATE('2026-11-10', 'YYYY-MM-DD') |
| CONVERT(데이터타입, 식[, 스타일]) | SQL Server에서 식을 지정한 데이터 타입으로 변환한다. | CONVERT(VARCHAR, GETDATE(), 112) → 'YYYYMMDD' |

CAST는 ANSI 표준 함수라 Oracle에서도 쓸 수 있고, 날짜 외에 다른 타입 변환에도 쓰인다. CONVERT는 CAST와 달리 날짜를 문자열로 바꿀 때 스타일 번호로 출력 형식을 지정할 수 있다. 위 예시의 112는 'YYYYMMDD' 형식을 뜻한다.

## NULL 관련 함수

NULL 관련 함수는 [[데이터베이스/NULL.md|NULL]]을 처리하기 위한 함수다.

| 함수 | 설명 |
|---|---|
| NVL/ISNULL(식1, 식2) | 식1이 NULL이면 식2를 반환하고, 아니면 식1을 반환한다. |
| NULLIF(식1, 식2) | 두 식이 같으면 NULL을, 다르면 식1을 반환한다. |
| COALESCE(식1, 식2, ...) | 나열된 식 중 NULL이 아닌 첫 번째 값을 반환한다. 모두 NULL이면 NULL을 반환한다. |

COALESCE는 인자를 여러 개 받을 수 있는 NVL의 확장판이라고 볼 수 있다.

```sql
SELECT NVL(NULL, 0),            -- 0
       NULLIF(100, 100),        -- NULL
       NULLIF(100, 200),        -- 100
       COALESCE(NULL, NULL, 3)  -- 3
FROM DUAL;
```
