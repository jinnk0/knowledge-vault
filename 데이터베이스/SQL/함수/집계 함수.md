집계 함수는 여러 행을 묶어 하나의 결과를 반환하는 [[데이터베이스/SQL/함수/함수.md|함수]]다. 주로 [[데이터베이스/SQL/SELECT/GROUP BY 절.md|GROUP BY 절]]로 소그룹을 나눈 뒤 SELECT 절이나 HAVING 절에서 쓴다.

## 종류

| 함수 | 설명 |
|---|---|
| COUNT(\*) | NULL 값을 포함한 행의 수를 출력한다. |
| COUNT(표현식) | 표현식의 값이 NULL인 것을 제외한 행의 수를 출력한다. |
| SUM(표현식) | 표현식의 NULL 값을 제외한 합계를 출력한다. |
| AVG(표현식) | 표현식의 NULL 값을 제외한 평균을 출력한다. |
| MAX(표현식) | 표현식의 최댓값을 출력한다. 문자, 날짜 데이터 타입에도 쓸 수 있다. |
| MIN(표현식) | 표현식의 최솟값을 출력한다. 문자, 날짜 데이터 타입에도 쓸 수 있다. |
| STDDEV(표현식) | 표현식의 표준 편차를 출력한다. SQL Server에서는 STDEV다. |
| VARIANCE(표현식) | 표현식의 분산을 출력한다. SQL Server에서는 VAR다. |
| 기타 통계 함수 | 벤더별로 다양한 통계식을 제공한다. |

STDDEV, VARIANCE는 Oracle의 함수 이름이고, SQL Server에서는 같은 기능을 STDEV, VAR라는 이름으로 제공한다. (출처: Oracle SQL Language Reference, Microsoft Learn)

SUM, AVG, MAX, MIN, STDDEV, VARIANCE는 표현식 앞에 DISTINCT나 ALL을 붙일 수 있다. [[데이터베이스/SQL/SELECT/SELECT.md|SELECT]]의 DISTINCT, ALL과 마찬가지로 DISTINCT는 중복 값을 1건으로 처리해 계산하고, ALL은 기본값으로 모든 값을 계산한다.

```sql
SUM([DISTINCT | ALL] 표현식)
```

## NULL 처리

COUNT(\*)를 제외한 집계 함수는 [[데이터베이스/NULL.md|NULL]] 값을 제외하고 계산한다. 그래서 같은 컬럼을 세더라도 COUNT(\*)와 COUNT(컬럼)의 결과가 다를 수 있다.

```sql
-- 부서 10의 보너스가 100, 200, NULL인 경우
SELECT 부서번호,
       COUNT(*),        -- 3
       COUNT(보너스),    -- 2
       SUM(보너스),      -- 300
       AVG(보너스),      -- 150 (NULL을 뺀 두 행의 평균)
       MAX(입사일)       -- 날짜 타입에도 쓸 수 있다
FROM 사원
GROUP BY 부서번호;
```
