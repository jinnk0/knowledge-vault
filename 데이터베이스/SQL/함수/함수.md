[[데이터베이스/SQL/SQL.md|SQL]]의 함수는 값을 한 행씩 처리하느냐, 여러 행을 묶어서 처리하느냐에 따라 두 종류로 나뉜다.

- **[[데이터베이스/SQL/함수/단일행 함수.md|단일행 함수]]**: 각 행의 값을 입력받아 행마다 하나의 결과를 반환한다. 입력 값의 타입에 따라 문자형, 숫자형, 날짜형, 변환형, NULL 관련 함수로 나뉜다.
- **[[데이터베이스/SQL/함수/집계 함수.md|집계 함수]]**: 여러 행을 묶어 하나의 결과를 반환한다. 주로 [[데이터베이스/SQL/SELECT/GROUP BY 절.md|GROUP BY 절]]과 함께 쓴다.

```sql
SELECT UPPER(이름) FROM 사원;  -- 단일행 함수: 사원 수만큼 결과가 나온다
SELECT COUNT(*) FROM 사원;     -- 집계 함수: 결과가 1건 나온다
```

Oracle과 SQL Server는 같은 기능의 함수 이름이 다른 경우가 많아, 하위 노트에서는 `Oracle 함수/SQL Server 함수` 순서로 함께 표기한다.
