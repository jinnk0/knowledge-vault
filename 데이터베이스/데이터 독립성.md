데이터 독립성(Data Independence)은 [[데이터베이스/스키마 구조.md|3단계 스키마 구조]]에서 하위 스키마가 변경되어도 상위 스키마가 영향을 받지 않는 성질이다. 스키마 구조를 3단계로 나누어 도입하는 이유가 바로 이 독립성을 확보하기 위해서이다.

| 구분 | 변경되는 스키마 | 영향받지 않는 스키마 |
|---|---|---|
| 논리적 데이터 독립성 | 개념 스키마 | 외부 스키마 |
| 물리적 데이터 독립성 | 내부(물리) 스키마 | 개념(논리) 스키마 |

## 논리적 데이터 독립성

개념 스키마가 바뀌어도 외부 스키마에 영향을 주지 않는다.

## 물리적 데이터 독립성

물리 스키마가 변경되어도 논리 스키마(개념 스키마)에 영향을 주지 않는다. 파일 저장 구조가 변경되어도 논리 스키마와 응용 프로그램에 영향을 주지 않는다.
