정규화(Normalization)는 [[데이터베이스/데이터 모델링/데이터 모델링.md|데이터 모델링]]에서 [[데이터베이스/데이터베이스.md|데이터베이스]]의 컬럼과 종속 관계를 단계적으로 정리하는 과정이다. 논리 데이터 모델을 상세화하는 과정의 대표적인 활동으로, [[데이터베이스/데이터 모델링/함수 종속성.md|함수 종속성]]을 분석해 테이블을 분해하는 방식으로 진행된다.

## 목적

정규화의 목적은 논리 데이터 모델의 일관성을 확보하고 중복을 제거해, 속성들이 가장 적절한 [[데이터베이스/데이터 모델링/엔터티.md|엔터티]]에 배치되도록 함으로써 보다 신뢰성 있는 데이터 구조를 얻는 데 있다. 구체적으로는 다음 세 가지를 얻고자 한다.

- **중복 제거**: 동일한 데이터가 반복 저장되는 것을 막아 저장 공간을 절약한다.
- **이상(Anomaly) 현상 방지**: 데이터를 삽입·수정·삭제할 때 발생할 수 있는 데이터 불일치와 모순을 막는다.
- **무결성 유지**: 데이터의 정확성과 일관성을 보장한다.

## 단계

정규화는 여러 단계로 이루어지며, 각 단계는 앞 단계를 만족한 상태에서 다음 조건을 추가로 요구한다. 각 단계의 조건을 만족한 상태를 정규형(Normal Form)이라 하고, 테이블을 그 정규형으로 만드는 작업을 1차 정규화, 2차 정규화처럼 부른다.

| 단계 | 조건 |
|---|---|
| 제1정규형 (1NF, 1차 정규화) | 모든 컬럼의 값은 더 이상 쪼갤 수 없는 원자값이어야 한다. |
| 제2정규형 (2NF, 2차 정규화) | 제1정규형을 만족하고, 기본키의 부분 집합이 결정자 역할을 하는 부분적 함수 종속을 제거한다. (완전 함수 종속 만족) |
| 제3정규형 (3NF, 3차 정규화) | 제2정규형을 만족하고, 기본키가 아닌 일반 컬럼 간에 발생하는 이행적 종속을 제거한다. |
| BCNF (보이스-코드 정규화) | 제3정규형을 만족하고, 모든 결정자가 후보키여야 한다. |

결정자와 종속 관계의 개념은 [[데이터베이스/데이터 모델링/함수 종속성.md|함수 종속성]], 후보키의 개념은 [[데이터베이스/데이터 모델링/키.md|키]] 노트에서 다룬다.

### 제1정규형 (1NF)

테이블의 모든 속성 값은 더 이상 쪼갤 수 없는 원자값(Atomic Value)을 가져야 한다. 한 컬럼에 여러 개의 값이 들어 있거나 반복되는 속성이 있다면 이를 분리한다. 즉 모든 인스턴스가 각 속성에 대해 반드시 하나의 값만 가져야 한다는 의미다.

### 제2정규형 (2NF)

제1정규형을 만족하고, 부분 함수 종속을 제거한 상태다. 기본키의 일부분에만 종속되는 속성을 다른 테이블로 분리하면, 남은 일반 속성은 모두 기본키 전체에 완전 함수 종속하게 된다.

### 제3정규형 (3NF)

제2정규형을 만족하고, 이행 함수 종속을 제거한 상태다. 이행적 종속은 A → B, B → C가 성립할 때 A → C도 성립하는 관계를 말한다. 기본키가 아닌 일반 속성(B)이 다른 일반 속성(C)을 종속시키는 경우를 다른 테이블로 분리해 A → C를 제거한다.

그 결과 제3정규형을 만족하는 엔터티의 일반 속성은 [[데이터베이스/데이터 모델링/식별자.md|주식별자]] 전체에 종속적이다.

## 정규화와 성능

정규화를 수행하면 중복 속성을 제거하므로 저장 용량을 최소화할 수 있고, 일반적으로 데이터 처리 성능도 향상된다.

다만 조회 성능은 저하될 수 있다. 정규화를 엄격하게 수행할수록 테이블이 잘게 쪼개지고, 흩어진 데이터를 다시 모으려면 조인(Join) 연산이 많아지기 때문이다. 조인은 상속된 식별자를 매핑키로 활용해 데이터를 결합하는 것으로, [[데이터베이스/데이터 모델링/관계.md|관계]] 노트에서 다룬다.

이처럼 정규화로 조회 성능이 떨어지는 경우, 성능 향상을 위해 의도적으로 테이블을 다시 합치거나 데이터를 중복시키는 반정규화(Denormalization)를 검토한다. 반정규화는 성능을 위해 데이터 중복을 허용하는 것이지만, 성능의 향상을 항상 보장하지는 않는다.

> 정규화가 조회 성능을 항상 떨어뜨리는 것도, 반정규화가 조회 성능을 항상 높이는 것도 아니다. 반정규화를 해도 조회 성능이 좋아지지 않을 수 있고, 때로는 정규화를 통해 성능이 향상되기도 한다.
