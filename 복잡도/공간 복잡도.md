[[복잡도/복잡도.md|복잡도]]의 한 종류인 공간 복잡도(Space Complexity)는 알고리즘이 사용하는 메모리 측면에서 얼마나 효율적인지 나타내는 지표다. 입력값에 대해 알고리즘이 사용하는 총 메모리 공간을 계산해서 측정하며, 분석 방식은 [[복잡도/시간 복잡도/시간 복잡도.md|시간 복잡도]] 분석과 거의 동일하다.

예를 들어 다음 코드는 크기가 $N$인 벡터를 생성하므로 공간 복잡도가 $O(n)$이다.

```cpp
vector<int> V;
for (int i = 0; i < N; i++) V.push_back(i);
```

크기가 $n \times n$인 2차원 배열을 만들어야 한다면 공간 복잡도는 $O(n^2)$이 된다.

## 보조 공간

공간 복잡도와 유사한 개념으로 보조 공간(Auxiliary Space)이 있다. 보조 공간은 입력에 사용되는 공간을 제외하고, 알고리즘이 추가로 사용하는 메모리 공간을 의미한다. 다음은 입력 배열의 합을 계산하는 코드다.

```cpp
int sum(int arr[], int n)
{
    int sum = 0;
    for (int i = 0; i < n; i++)
    {
        sum += arr[i];
    }
    return sum;
}
```

이 알고리즘은 입력 배열 외에 `sum`이라는 변수 하나만 추가로 선언한다. 따라서 보조 공간은 $O(1)$이지만, 입력 배열까지 포함한 공간 복잡도는 $O(n)$이다.

정렬·탐색 알고리즘별 공간 복잡도와 보조 공간을 정리하면 다음과 같다.

| 알고리즘 | 공간 복잡도 | 보조 공간 |
|---|---|---|
| 선형 탐색(Linear Search) | $O(n)$ | $O(1)$ |
| 이진 탐색(Binary Search) | $O(n)$ | $O(1)$ |
| 버블 정렬(Bubble Sort) | $O(n)$ | $O(1)$ |
| 선택 정렬(Selection Sort) | $O(n)$ | $O(1)$ |
| 삽입 정렬(Insertion Sort) | $O(n)$ | $O(1)$ |
| 병합 정렬(Merge Sort) | $O(n)$ | $O(n)$ |
| 퀵 정렬(Quick Sort) | $O(n)$ | $O(\log n)$ |
| 힙 정렬(Heap Sort) | $O(n)$ | $O(n)$ |
| 버킷 정렬(Bucket Sort) | $O(n)$ | $O(n)$ |
| 기수 정렬(Radix Sort) | $O(n+k)$ | $O(n+k)$ |
| 팀 정렬(Tim Sort) | $O(n)$ | $O(n)$ |
| 셸 정렬(Shell Sort) | $O(n)$ | $O(1)$ |

## 시간 복잡도와의 차이

| 시간 복잡도 | 공간 복잡도 |
|---|---|
| 알고리즘·프로그램이 실행되는 데 걸리는 시간을 입력 길이에 대한 함수로 나타낸 것이다. | 알고리즘이 실행되는 동안 사용하는 총 메모리의 양이다. |
| 입력 크기에 의존한다. | 주로 보조 공간(추가로 사용된 공간)의 크기에 의존한다. |
| 현대 하드웨어에서는 시간 복잡도를 줄이는 것이 더 중요하다. | 현대 하드웨어에서는 시간 복잡도에 비해 공간 복잡도를 줄이는 것의 중요성이 상대적으로 낮다. |
