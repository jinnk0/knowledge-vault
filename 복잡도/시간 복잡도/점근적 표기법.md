점근적 표기법(Asymptotic Notation)은 입력값이 무한대로 커질 때 [[복잡도/시간 복잡도/시간 복잡도.md|시간 복잡도]]가 어떻게 증가하는지를 설명하는 수학적 표기법이다. 같은 알고리즘이라도 입력에 따라 걸리는 시간이 다를 수 있으므로, 최악·최선·평균의 경우를 각각 빅오, 빅오메가, 빅세타 세 가지 표기법으로 구분해서 설명한다.

## 종류

### 빅오 표기법 (Big-O)

알고리즘의 최악의 경우(Worst-case) 실행 시간을 설명한다. 입력 $n$에 대해 최악의 시나리오에서 걸리는 연산 횟수를 세어 계산한다.

$$O(g(n)) = \{ f(n) : \text{모든 } n \ge n_0\text{에 대해 } 0 \le f(n) \le cg(n)\text{인 양의 상수 } c\text{와 } n_0\text{이 존재함} \}$$

### 빅오메가 표기법 (Big Omega)

알고리즘의 최선의 경우(Best-case) 실행 시간을 설명한다. 입력 $n$에 대해 최선의 시나리오에서 걸리는 연산 횟수를 세어 계산한다.

$$\Omega(g(n)) = \{ f(n) : \text{모든 } n \ge n_0\text{에 대해 } 0 \le cg(n) \le f(n)\text{인 양의 상수 } c\text{와 } n_0\text{이 존재함} \}$$

### 빅세타 표기법 (Big Theta)

함수를 위아래에서 동시에 감싸므로 정확한 점근적 동작을 정의하며, 알고리즘의 평균 실행 시간을 분석하는 데 쓰인다.

$$\Theta(g(n)) = \{ f(n) : \text{모든 } n \ge n_0\text{에 대해 } 0 \le c_1g(n) \le f(n) \le c_2g(n)\text{인 양의 상수 } c_1, c_2, n_0\text{이 존재함} \}$$

## 표기법의 의미

$O, \Omega, \Theta$는 함수가 아니라 집합이라는 점에 유의해야 한다. 예를 들어 $O(n)$은 선형 함수 $f(n) = n$과 같은 속도로 증가하는 모든 함수의 집합을 나타낸다.

빅오 표기법은 상한선(Upper Bound)을 말할 수 있는 편리한 방법을 제공한다. 예를 들어 어떤 알고리즘의 시간 복잡도가 $O(n^3)$이라면, 실행 시간이 최대 삼차(Cubic) 형태라는 것을 의미한다.

실행 시간(Running Time)과 시간 복잡도(Time Complexity)는 서로 다른 개념이다. 알고리즘의 실행 시간이 $T(n) = 3n^2 + 4n + 2$라면, 시간 복잡도는 가장 차수가 높은 항만 남긴 $O(n^2)$이 된다.
