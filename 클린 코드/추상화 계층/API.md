[[클린 코드/추상화 계층/추상화 계층.md|추상화 계층]]을 명확하게 만드는 데 도움이 되는 관점. 코드를 호출하는 쪽에 공개할 개념만 형식화해서 정의하고, 서비스의 나머지 구현 세부 사항은 모두 그 뒤에 감추는 것이 API(Application Programming Interface)다.

코드를 작성할 때는 두 가지 측면을 구분해서 고려해야 한다.

- **코드를 호출할 때 볼 수 있는 내용**: 퍼블릭 클래스, 인터페이스, 함수(메서드)의 이름·입력 매개변수·반환 유형이 표현하고자 하는 개념, 그리고 코드를 올바르게 사용하기 위해 알아야 하는 추가 정보(예: 호출 순서)
- **코드를 호출할 때 볼 수 없는 내용**: 구현 세부 사항

API는 호출하는 쪽에 공개할 개념만 정의하면 되고 그 이외의 모든 것은 구현 세부 사항이므로, 코드를 API의 관점에서 생각하면 추상화 계층을 명확하게 만드는 데 도움이 된다.
